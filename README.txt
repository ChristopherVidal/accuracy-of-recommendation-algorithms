What is the sample movie review data file?

The sample data file contains fictional movie reviews given by users. On the first line there are two numbers - the first represents the number of users, while the second is the number of reviewable movies. The second line contains the id of every user. The third line contains every movie id. Every subsequent line contain all the movie reviews given by some user. The fourth line contains the reviews of the user with the first id on line 2, the fifth line contains the reviews of the user with the second id on line 2, and so on. Similarly, the first review on a line containing reviews is for the movie with the first id on line 3, the second review on a line containing reviews is for the movie with the second id on line 3, and so on.
